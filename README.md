⚖️ Law Docs

Welcome to Law Docs!

Law Docs is a beginner legal technology project that aims to organize legal documents and provide useful legal information through a simple and user-friendly website.

🎯 Project Goal

To combine Law and Technology by creating digital solutions that make legal information easier to access and understand.

💻 Technologies Used

- HTML5
- CSS3
- JavaScript

✨ Features

- Arabic RTL interface.
- Simple and user-friendly design.
- Organized legal information.
- Responsive website development.
